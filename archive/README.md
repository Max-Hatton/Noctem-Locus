# Historical builds

Noctem Locus began as **Astronomy Companion**. Historical builds from v0.1 through v0.9.0 are preserved in this repository as a compressed archive.

The archive is stored as base64-encoded parts under `archive/encoded/` so it can be committed through the GitHub integration without losing any binary data. Running:

```bash
npm run prepare
```

reconstructs:

```text
archive/noctem-locus-history-v0.1-v0.9.0.tar.gz
```

That archive contains the original source/portable build files for:

- v0.1
- v0.2
- v0.3
- v0.3.1
- v0.4
- v0.4.1
- v0.5
- v0.5.1
- v0.6
- v0.7
- v0.7.1
- v0.7.2
- v0.7.2.1
- v0.8
- v0.8.1
- v0.9.0

See the root `CHANGELOG.md` for the feature history.
