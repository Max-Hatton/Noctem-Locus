ASTRONOMY COMPANION v0.3.1 — SMART APP CONTROL SAFE PACKAGE

HOW TO RUN
1. Extract this ZIP to a normal folder (Documents is fine).
2. Double-click "Astronomy Companion v0.3.1.html".
3. It will open in your normal web browser.

There are NO .exe, .bat, .cmd, .ps1, MSI, or installer files in this package.
The astronomy code, styles, and UI are contained in the HTML file and run locally in your browser.
No internet connection is required for the built-in astronomy calculations.

NOTES
- Manual observing-location entry works offline.
- Browser/device geolocation may depend on browser permissions and may not be available for a local file. If it fails, enter latitude/longitude manually.
- Settings are stored locally by the browser on this computer.
- Night mode and the app dimmer work normally.

WHY THIS VERSION EXISTS
The previous v0.3 portable launcher used a Windows .bat file only to open the local HTML in an app-like browser window. Windows Smart App Control can block unsigned scripts/executables. v0.3.1 removes that launcher entirely rather than asking you to disable security protections.
