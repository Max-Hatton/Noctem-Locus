ASTRONOMY COMPANION v0.3 - PORTABLE WINDOWS BUILD

1. Double-click "Launch Astronomy Companion.bat".
2. Go to Settings and set your observing location.
3. Optional: run "Create Desktop Shortcut.bat" once.

The astronomy engine is contained inside "Astronomy Companion.html" and does
not require an internet astronomy service. You can also double-click the HTML
file directly if you do not want to use the launcher.

Night mode shortcut: N
Brightness range: 5% to 100%
Deep Night preset: 12%
