Astronomy Companion v0.4.1 — Smart App Safe

HOW TO RUN
1. Extract this ZIP.
2. Double-click "Astronomy Companion v0.4.1.html".
3. It runs locally in your default browser. No installer or scripts are included.

WHAT CHANGED IN v0.4.1
- Default telescope is now Orion AstroView 90mm EQ #9024.
- Aperture: 90 mm.
- Focal length: 910 mm.
- Focal ratio: about f/10.1.
- Existing v0.4 saved settings are preserved. The old placeholder scope-90 profile is upgraded automatically if its focal length was blank.
- Equipment calculations now work immediately for the default telescope.

OFFLINE / SECURITY
- No EXE, BAT, CMD, PowerShell, MSI, or installer.
- Astronomy calculations and catalogs are embedded in the HTML app.
