Astronomy Companion v0.4 — Offline Portable Build

HOW TO RUN
1. Extract this ZIP.
2. Double-click "Astronomy Companion v0.4.html".
3. It opens in your normal browser and runs locally.

WHAT'S NEW IN v0.4
- Search the solar system, 49 bright stars, and 110 Messier catalog entries.
- Live Alt/Az and rise/set calculations for stars and Messier objects.
- J2000 coordinates are precessed to the current date for pointing calculations.
- "Observe Now" quick rating based on altitude, twilight, Moon, object brightness, and saved aperture.
- Telescope profiles and an editable current Orion 90 mm starter profile.
- Eyepiece case with magnification, exit pupil, focal ratio, and approximate true field calculations.
- Best Messier targets shown on the Tonight page.
- Night mode and software dimming remain fully local.

IMPORTANT
The exact model/focal length of the current Orion 90 mm telescope has not been confirmed, so v0.4 leaves its focal length blank. Enter the focal length printed on the telescope tube before using the eyepiece calculations.

This build contains no executable, batch, PowerShell, MSI, or installer file.

CATALOG DATA NOTES
The Messier coordinate/magnitude seed data were adapted from the public lgbouma/obs Messier CSV. M102 is treated as the Spindle Galaxy (NGC 5866), matching NASA's Hubble Messier catalog convention.
