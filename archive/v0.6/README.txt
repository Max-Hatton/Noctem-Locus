Astronomy Companion v0.6 — Smart App Safe portable build

RUN IT
1. Extract this ZIP.
2. Double-click "Astronomy Companion v0.6.html".
3. It opens in your default browser and runs locally/offline.

NEW IN v0.6
- Push-To / star-hop guidance page
- Pick any catalog target and choose from nearby visible bright reference stars
- Live left/right + up/down sky movement guidance
- Great-circle angular separation and estimated finder-field count
- Editable finder field-of-view setting
- Manual telescope Alt/Az reticle for testing the future sensor pipeline
- SCOPE reticle appears on the Sky Map when telescope pointing is set
- Future hardware API: window.astronomyCompanion.setTelescopePointing(altitudeDeg, azimuthDeg)
- Push-To buttons from Find Object and Sky Map
- P keyboard shortcut opens Push-To

IMPORTANT
Push-To left/right and up/down are sky directions. On an equatorial mount they are not the same thing as RA/Dec slow-motion knob directions. Near the zenith, horizontal directions also become less intuitive.

The built-in reference-star list currently uses the app's bright-star catalog, so v0.6 is a useful first Push-To layer rather than a full dense finder-chart replacement.

No executable, launcher script, fetch call, or external web resource is required.
